파일제목 : 엔티티 타입(지금이거만지고있을김주경등은새로파일만들일없음)
Name : 체력바 위에 뜰 몹 이름
HP : 최대체력
MoveSpeed : 이속, 초당 몇 가는지(유니티 단위)
JumpPower : 점프력 나타내는 측도
AttackSpeed : 공격 빈도 (초당 몇번)
AttackDamage : 공격력 (곱적용)
InvincibleTime : 소환 후 무적 시간 (너무 짧으면 버그 생길 수 있음)
GroundBoxOffset[X/Y] : 바닥 감지하는 영역 위치(스프라이트 중앙 기준)
GroundBoxSize[X/Y] : 바닥 감지하는 영역 크기(영역 위치를 중앙으로 함)

// Enemy 전용
AttackCooldown : 공격 쿨타임
AggroThreshold : 어그로 수치 임계점 (이거보다 어그로 수치가 낮은 엔티티한테 어그로 안끌림)
AggroCoefficient : 어그로 수치 계수 (어그로 수치 = (어그로 수치 계수) / (거리))
